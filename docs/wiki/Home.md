# Snaral Wiki

Snaral is a MIDI-playable drum and bass synthesiser built around a stable, centred sub layer and a separately
shaped mid voice. **Prototype:** an eight-voice MIDI sine instrument with five host-automatable macros. Only the
Weight macro currently changes the sine voice level; Growl, Bite, Motion and Space await their DSP destinations.
