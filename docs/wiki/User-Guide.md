# User Guide

Snaral is a prototype and is not production-ready. Current behaviour:

- Eight-voice MIDI sine instrument.
- Five host-automatable macro controls. **Weight** changes the sine voice level. Growl, Bite, Motion and Space are specified but not yet connected to DSP.
- Build the VST3 and standalone targets from source (see the Developer Guide). Successful compilation does not establish DAW compatibility or a release.

Specifications for planned sound design: `docs/DARK_DNB_BASS_SYNTH_DESIGN_BRIEF.md`, `docs/SNARAL_FEATURE_SPEC_INDEX.md`.
